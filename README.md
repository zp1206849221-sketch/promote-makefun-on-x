# Promote make.fun on X

This repository is an entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty ($250). The entry itself is a post on X that quotes make.fun's announcement and invites others to create their own bounties: [read the post](https://x.com/zhaopen08802120/status/2125405878224658940). The program in this repository (`main.ts`) simply copies `POST.json`, which names the post's address, into the output directory for grading.
